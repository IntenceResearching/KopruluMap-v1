# Правка данных в Google Sheets

Инструкция для ручного редактирования вкладок `systems` и `places`. Источник данных — опубликованные вкладки Google Sheets; файлы `data/systems.csv` и `data/places.csv` в репозитории являются выгрузками и могут быть перезаписаны синхронизацией. Правьте таблицу, а не эти CSV.

## Теги и типы

### Вкладка `systems` — колонка `type`

У системы одно значение `type`:

| Значение | Значение для каталога |
|---|---|
| `none` | Нет выделения; метка в досье не показывается. Вписывайте `none`, не оставляйте ячейку пустой. |
| `capital` | Столица; в досье показывается метка «Столица». |
| `unknow` | Тип неизвестен; в досье показывается «Неизвестный тип». Используйте именно `unknow`. |

Значения вводятся латиницей, строчными буквами, без пробелов. `unknown` не является рекомендуемым значением — используйте `unknow`.

### Вкладка `places` — колонка `type`

У места указывается один основной тип:

| Значение | Примеры / назначение |
|---|---|
| `planet` | Планета |
| `moon` | Луна |
| `asteroid` | Астероид или пояс астероидов |
| `station` | Станция |
| `platform` | Платформа |
| `other` | Иное место, не подходящее под перечисленные типы |

Это **тип места**, а не тег системы. Несколько значений через запятую или точку с запятой в одной ячейке не указывайте.

> В текущей выгрузке `places` заголовок `type` отсутствует, хотя типы есть в коде и шаблоне. Добавьте колонку `type` на вкладку `places` и заполните её для строк. Пока её нет, фронтенд по умолчанию считает записи планетами.

## Заголовки вкладок

Текущие опубликованные листы используют `system_id` как идентификатор системы и `ID` как идентификатор места. Чтобы не менять существующие поля, добавьте `type` в указанные позиции:

```csv
systems: name,system_id,type,x,y,faction,description,source_url
places:  name,ID,type,system_id,x,y,faction,description,source_url
```

Имена заголовков важны. Не переименовывайте и не удаляйте остальные столбцы при добавлении `type`. Код принимает `id` и `ID`/`system_id` как варианты идентификатора, но текущие названия удобнее оставить как есть.

## Как заполнять строки

- `system_id` — идентификатор связанной системы. Для места без системы оставьте его пустым и заполните собственные `x` и `y`.
- `x`, `y` — числа с точкой в качестве десятичного разделителя. Если координаты места пусты, укажите `system_id`: координаты будут унаследованы от системы.
- `faction`, `description`, `source_url` — обычный текст, описание и URL источника.
- Не меняйте существующие ID: они используются для связей и поиска записей.
- Для CSV используйте запятую как разделитель столбцов. Если в значении есть запятая, оставьте обработку экспорта Google Sheets — не собирайте CSV вручную без кавычек.

## Перед публикацией

1. Проверьте, что первая строка содержит заголовки, а `type` добавлен в правильную вкладку.
2. Проверьте значения `type` по таблицам выше; в системах ставьте `none`, а не пустую ячейку, если выделение не требуется.
3. Проверьте уникальность идентификаторов и ссылки `places.system_id` на существующие системы.
4. Опубликуйте каждую вкладку отдельно в формате CSV (Google Sheets → **Файл → Поделиться → Опубликовать в интернете**).
5. После публикации дождитесь очередной синхронизации или запустите workflow синка.
