# Перепроверка модуля определения местоположения

Дата проверки: **2026-10-13**

## Короткий ответ

Да, модуль есть: `tools/verify_overrides_on_map.py`.

Это не браузерная геолокация и не генератор вымышленных координат. Он работает с картой Копрулу 10000×10000 и выполняет две задачи:

1. проверяет, что опубликованная координата системы действительно находится рядом с её подписью на растре;
2. с ключом `--locate` ищет переехавшую подпись по всей карте и предлагает центр системного кольца.

Планеты и другие места обычно не получают отдельную орбитальную точку: они наследуют положение своей системы. Отдельные подписи объектов хранятся в `data/map-labels.json`.

## Из чего состоит координатный контур

- `tools/download_drive_file.py` — загружает исходную карту из публичного Google Drive.
- `tools/verify_overrides_on_map.py` — OCR-проверка и полный поиск подписи.
- `data/system-overrides.json` — 25 координат, снятых непосредственно с карты.
- `data/systems.json` — условные координаты и системы без координат.
- `app.js:resolveSystemPosition()` — применяет приоритет: локальная правка → опубликованный override → условная координата.
- `tools/sync_system_overrides.py` — принимает проверенные координаты из опубликованного CSV.
- `tools/validate_data.py` — проверяет диапазоны, ID и невозможность двух систем занимать один центр.

## Найденная проблема полного поиска

Старая реализация `--locate` уменьшала всю карту с 10000 до 5000 px. Мелкие подписи теряли читаемость. Контрольный тест с намеренно неверной координатой Айура `1000,1000` не смог найти даже подпись `Айур`.

Модуль исправлен:

- карта сканируется перекрывающимися тайлами по 2000 px без предварительной потери разрешения;
- каждый тайл переводится в контрастный grayscale и увеличивается в 2 раза;
- OCR умеет собирать фразы из двух-трёх соседних слов;
- до запуска проверяется наличие языков Tesseract `rus` и `eng`;
- координата центра текста переводится в центр кольца с вертикальной поправкой 31 px.

Повторный контрольный тест:

- ошибочная исходная точка Айура: `1000,1000`;
- найденный центр подписи: `6682,5107`;
- восстановленный центр кольца: **6682,5076**;
- фактический опубликованный центр: **6682,5076**;
- результат: точное совпадение.

## Интеграция в pipeline

GitHub workflow теперь после загрузки Drive-карты:

1. устанавливает Tesseract и языки `rus+eng`;
2. запускает `verify_overrides_on_map.py` для всех 25 опубликованных точек;
3. останавливает публикацию, если подтверждено менее 80%;
4. только после этого строит 534 тайла Pages.

Таким образом, модуль не просто присутствует в проекте, а включён в автоматическую сборку.

## Ограничения

- Модуль может найти только реально напечатанную и читаемую подпись на карте.
- Отсутствие подписи не означает отсутствие системы в лоре.
- OCR-поиск выдаёт предложение; автоматическое применение новой координаты намеренно не выполняется без проверки.
- Станции, луны и планеты без собственной подписи используют координату системы или остаются без точки.
